## 已登记的空间桥接与 DEM Mock

- `assets/map/metadata/spatial_bridge.json`：WGS84 → LCC(P) → SVG(V) 参数和误差。
- `assets/map/metadata/control-points.json`：17 个 G/V 控制点。
- `assets/map/raster/mock_base.png`：3025×2137 的纯模拟高程纹理，仅用于管线验证。
- `tools/render_dem.py`：真实 DEM 缺失时的可重复 Mock 渲染脚本。

EPS 不是天然的 GIS 数据格式：可能包含 Illustrator/Corel 私有结构、文字和印刷图层，且当前头部未提供可直接使用的 CRS。不能把其原始坐标当作经纬度。

当前 1:2200 万 EPS 文件在 PostScript 标识前带有二进制预览头，后续转换工具必须支持 Binary EPS 或先经过可验证的预处理；不能直接假设它是纯文本 SVG 来源。

## 地图要素清单

地理事实层（必须来自官方/权威）：中国主体几何、国界、一级行政区界线、海岸线、岛屿、南海相关插图/标注、需要展示的河流和城市坐标。参考图中的省界颜色、城市标签位置如非官方事实，只能作为表现配置。

视觉表现层（程序可生成）：海域背景、DEM hillshade、坡度/高度纹理、晨光渐变、阴影、发光、星点、经纬网样式、面板和标记样式。

动态数据层（程序计算）：太阳高度角/方位角、晨光阶段、昼夜分界、城市日出/日落/曙光时刻、节气状态、时间轴插值、主/对比差值。

## 推荐资产链路

```text
官方 EPS（原件只读）
  -> 版本/哈希/许可登记
  -> 可重复的 EPS→SVG/PDF 转换
  -> 按图层或颜色拆分几何
  -> 官方几何的 land/boundary/coast/island/inset 资产
  -> 生成中国主体 mask 与地图 manifest
  -> 与控制点/投影配置绑定
  -> 浏览器 SVG 几何 + Canvas 动态场合成
```

转换时保留原始路径，不做平滑、简化、补岛或边界修正。任何简化只能建立独立的低分辨率展示层，并记录容差、用途和与原件的差异。

## EPS、SVG、GeoJSON、Canvas、WebGL 的取舍

- **EPS**：归档和人工核验格式，适合印刷，不适合浏览器运行时。
- **SVG**：首选的静态几何承载格式。支持清晰边界、mask、标签和 CSS 样式，适合本项目的固定全国视图。
- **GeoJSON**：当需要经纬网、城市投影、地理命中、未来缩放或与 DEM 在地理坐标中计算时使用。必须从官方几何或有明确授权的 GIS 派生，不用第三方猜测轮廓替换官方资产。
- **JPG/PNG**：只用于人工预览、回归截图或最终合成的纹理快照；不适合作为权威几何、动态分界或可缩放边界来源，也不能替代 SVG/GeoJSON。
- **Canvas 2D**：首选动态光场、DEM 灰度纹理和昼夜分界的每像素渲染；可放在 SVG 下方或上方并用同一 viewBox 对齐。
- **WebGL**：不是 MVP 必需。只有在实测 4K 视图、长时间播放或多层高分辨率纹理达不到帧率时，才评估 WebGL/WebGPU。

## 投影与坐标对齐

1. 优先从 EPS 图层、附带说明或官方元数据获取投影和经纬网控制点。
2. 若 EPS 仅有印刷坐标，建立 `map-manifest.json`，登记至少 3–6 个可识别的经纬控制点和像素/路径坐标，选择与官方投影一致的仿射或投影变换。
3. 对城市、经纬网和太阳场统一使用 `projectLonLat()`，禁止在各组件内重复写 `minLon/maxLon` 之类的临时线性映射。
4. 变换只用于把经纬数据投影到官方图形的坐标系，不得对国界路径做自由形变。

## 官方地图 + DEM + Mask

该组合是合理且推荐的：官方几何决定哪里是中国，DEM 提供地形高程，mask 限制纹理只出现在官方主体，太阳场决定色温和亮度。建议流程：

1. 下载并归档许可允许使用的 30–90 m DEM。
2. 裁切中国及必要缓冲区，重采样到首屏纹理分辨率。
3. 计算 hillshade、坡度、归一化高程；不把 DEM 的海岸线或行政边界写回官方几何。
4. 通过官方 land mask 裁切纹理；海岛和南海插图使用独立官方层。
5. 将 hillshade 以低对比度叠加在地理底色上，再乘以动态晨光色场。

地形视觉只表达宏观地貌质感，不宣称局地真实光照或可见天气。若未来加入地形遮挡日出，应作为单独科学模型并明确假设。

## 动态晨光与昼夜分界

在每个时间点计算太阳赤纬/赤经和格网点太阳几何高度角；用同一字段驱动：

- 连续色彩（深夜 → 天文/航海/民用曙光 → 白昼）；
- 阶段阈值和图例；
- 太阳高度为零或约 -0.833° 的分界线；
- 城市阶段、日出和对比读数。

`SolarState` 与 `MapGeometry` 分离，时间轴改变只重算动态纹理和标记，不重建或修改地图路径。

## 必须核验的地图问题

- 三份 EPS 的完整标题、图层命名、是否含南海插图/河流/文字。
- 正式来源机构、版本/出版日期、审图号和网页发布许可。
- EPS 是否包含有效经纬网或可复现控制点。
- 省界是否为一级行政区，是否存在印刷版合并/隐藏图层。
