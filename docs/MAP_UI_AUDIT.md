## 审计结果

| 项目 | 当前审计结论 | 优先级 | 本轮处理 |
| --- | --- | --- | --- |

| 城市点与名称 | 二者曾同属一个按钮，但按钮采用布局坐标和整体变换，面板态地图变换造成误读。 | P0 | 每座城市改为一个 V 坐标锚点，内含点与相对偏移名称；只有锚点获屏幕坐标。 |
| 南海 inset | 来源为 `clean-map.svg`，`viewBox` 为 `0 0 3025.3333 2137.3333`。该文件有 859 个 path、0 个 `display:none` / `visibility:hidden` 节点，未发现低于 0.2 的显式 opacity 节点；页面容器未裁切。 | P0 | 保持该官方派生对象完整可见，降低外部泛光以提升细小官方线段的可读性。该层不按主图 CRS 重投影。 |
| 右侧蓝色海岸线 | 源自 `clean-map.svg` 内路径的 presentation style，例如 `stroke:#4b7892; stroke-opacity:0.7`，不是背景或 DOM 城市层。 | P1 | 该 SVG 稳定地以 `<img>` 载入，页面 CSS 不能安全选择其内部单独路径。本轮采用低强度的容器级暖色滤镜与整体泛光，使原始蓝色在网页呈现中收敛为金色系；未伪造逐路径语义重着色。 |
| 外轮廓亮度 | `.map-image` 的 `drop-shadow(0 0 6px rgba(220,190,120,.5))` 叠加在 SVG 原始线色之上。 | P1 | 调整为 `4px / .4`，约降低 20% 的外部亮感。 |
| 小点 | DOM 城市层有 11 个基于人工采集 V 坐标的交互标注；3 个南海控制点不作为城市标记。背景星点来自 `assets/images/bg-canvas.jpg`；页面未使用 Canvas。SVG 内仍有大量短路径/小岛对象，均为官方派生图层或语义尚未逐项分类的 UNKNOWN，不能删除。 | P0 | 保留城市点、背景星点及 SVG 对象；不删除未知地图对象。 |
| 经纬网 | 原顶部/左侧度数由 CSS 百分比分布，未使用 SpatialBridge，不是真实经纬网。 | P0 | 隐藏，待后续使用 SpatialBridge 生成并复核后才可显示。 |
| 标题 | 现有标题为“曦行神州”与不完整的“晨光”。 | P1 | 更正为“曦行神州”与竖排、深红印章样式的“万里晨光”。 |

## 数据与边界

- 城市 V 坐标来自 `assets/map/metadata/control-points.json`，其 `visualSource` 指向经人工核验的 Audit SVG。它们用于静态视觉锚定，不构成新的地理计算结果。
- 昆明尚无已采集的 V 坐标。因此快捷入口明确禁用并标注“待采点”，未猜测或补造位置。
- 南海 inset 内实际保留的是 `clean-map.svg` 已有的官方路径，包括 inset 框内的线状和岛屿形短路径；本轮没有新增、删除、裁切或重绘其中任何对象。

## 后续待办

1. 若后续需要国界、省界、海岸线和 inset 框具有不同的色阶，必须先完成官方对象的语义分类，并采用可审计的非几何样式层；不能按视觉猜测拆分路径。
2. 使用已验证的 SpatialBridge 参数生成主图经纬网；南海 inset 保持独立，不继承主图网格。
3. 为昆明采集人工核验 V 坐标后再启用其交互入口。
