# Phase 1C-44：东方天文图自有风格收敛

## 目标

在保留官方地图几何和现有天文计算链的前提下，停止对参考图的逐像素复刻，形成“东方天文图 + 克制地形浮雕 + 晨光时间带”的项目自有视觉风格。

## 当前表现

- 夜面：深蓝冷色，保持海域与页面背景的整体基调。
- 晨光：蓝灰至蓝紫的连续过渡，不使用固定屏幕方向色块。
- 交界：暗金宽光带叠加细核心线，避免只剩孤立亮线。
- 白昼：低饱和、连续的暖金陆地层。
- 地形：DEM hillshade、法线和多尺度细节参与光照，但压低高频对比，服务于晨光叙事。
- 线划：官方主图纯线划运行时置于太阳层之上，省界、国界和城市标记保持清晰。
- 南海 inset：保持独立官方图层，不参与大陆陆地 Mask。
- 地图比例：保持现有构图，不缩小主体地图。

## 技术约束

- 保留 UTC、WGS84、太阳高度角、太阳方位角、LCC、SpatialBridge 和 SVG V 坐标链。
- 未修改官方 EPS/SVG 几何。
- 未使用手绘或生成式轮廓作为地理数据。
- DEM 仅用于视觉起伏和受光表现，不改变地图边界。
