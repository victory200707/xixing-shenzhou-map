# Phase 1C-18: 1123.svg 幕布处理结果审计

## 结论

`1123.svg` 是目前最适合作为视觉参考和后续候选处理的同源文件。它已经去除了 `777.svg` 中的整幅嵌入 JPEG 幕布，不会把深蓝背景带入网站。

但 `1123.svg` 不能直接作为陆地 Mask：文件只包含 3088 个矢量 `path`，其中同时混有外轮廓、省界、城市标注、岛屿和南海附图对象；没有可审计的独立陆地填充语义。将全部 path 直接填充会把文字、边界和南海内容一起纳入光场，导致再次出现错位或“只有轮廓发光”的问题。

## 与 777.svg 的差异

`777.svg` 与 `1123.svg` 的矢量主体来自同一组编辑结果，但 `777.svg` 额外包含一个 `405.34167 × 270.93332` 的内嵌 JPEG，使用 `preserveAspectRatio="none"` 铺满页面。该 JPEG 就是深蓝幕布和星光纹理来源。

`1123.svg` 没有该 `<image>` 对象，因此可以正常作为透明矢量素材读取。

- `assets/map/svg/1123-visual-mask.svg`：仅用于候选审查，路径重新着色为白色，未改写几何；不加载到页面。

- `analysis/1123-outer-1200.png`：外轮廓候选诊断图。

## 页面使用边界

当前页面仍使用既有 `ne-china-visual-mask.png`，太阳计算链和官方底图未因本审计改变。`1123-visual-mask.svg` 未接入生产渲染，因为它不是封闭的陆地面。

任何后续接入必须先完成：

1. 在 1123 坐标系与网站 V 坐标系之间建立可复核的控制点配准；
2. 从外轮廓生成独立栅格填充，并通过黑白图和底图叠加检查；
3. 确认西藏南部、沿海、海南、台湾和南海 inset 不发生外溢；
4. 明确标注 `APPROXIMATE_VISUAL_MASK - NOT A GEOGRAPHIC SOURCE`。
