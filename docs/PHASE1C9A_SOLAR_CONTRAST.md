# Phase 1C-9A：连续昼夜明暗场增强

日期：2026-08-26

## 实施结果

现有 `solar-field.js` 保留原有 WGS84 → LCC → SpatialBridge(P→V) → 屏幕坐标链和真实太阳高度角采样。光场现在使用普通 alpha 合成，按太阳高度角连续插值为三段：

- 深夜（`altitude < -6°`）：冷深蓝暗化，目标 opacity `0.34`，随高度平滑过渡至晨昏段；
- 晨昏过渡（`-6° .. -0.833°`）：低饱和蓝紫到暗金，opacity `0.16 .. 0.18`；
- 白昼（`altitude >= -0.833°`）：蓝灰提亮，opacity `0.098 .. 0.14`，不使用大面积黄色。

所有段使用 `smoothstep` 插值，离屏低分辨率场通过 Canvas image smoothing 放大，避免方格、块状边缘和梯形采样边界。0° 几何昼夜边界与 -0.833° 民用日出边界仍由 WGS84 采样曲线绘制，官方 SVG 位于光场上方。

CSS 光场层改为 `mix-blend-mode: normal; opacity: 1`，使深夜 alpha 真正降低底图亮度；图层顺序仍为 terrain → solar → official SVG → inset → city/UI。

## 参数

```js
{
  nightOpacity: 0.34,
  twilightOpacity: 0.16,
  daylightOpacity: 0.14,
  warmBandOpacity: 0.18,
  terminatorGlow: 0.34,
  boundaryPreservation: 0.86
}
```

## 限制与保护声明

当前没有可靠官方陆地 Mask，光场仍覆盖实际地图显示矩形并做边缘渐隐。这是技术范围光场预览，不是中国陆地裁切、真实地形或正式地图底色。南海 inset 不参与主图太阳场采样，继续作为独立官方展示层。

本阶段未修改任何官方 EPS、Audit SVG、Clean SVG、Presentation SVG、官方南海 SVG 或南海展示派生 SVG；未接入 DEM、未修改 Mask、未新增太阳算法或 UI 结构。
