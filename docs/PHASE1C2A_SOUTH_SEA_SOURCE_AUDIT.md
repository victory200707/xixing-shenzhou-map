# 南海附图源保真核验与派生修复

## 结论

当前网页出现“外框内又有一个空小框”的原因不是官方 EPS 被重绘，而是
`tools/clean_map_svg.py` 对 `official-audit.svg` 进行了过度清洗：它保留了
南海附图外框和部分线段，却删除了附图内的填充岛屿、文字和标题/比例尺路径。

原始官方渲染预览显示，右下框是一个完整的官方南海诸岛附图；右下小矩形是
附图中的标题/比例尺信息块，不是项目新增的第二个南海框。

对象级对照显示：`official-audit.svg` 有 3730 个路径，`clean-map.svg` 只剩
859 个；按附图范围识别到的 594 个源路径中，清洗层只保留了 50 个，544 个
填充/文字/符号路径被清洗规则移除。这正是当前空框视觉的直接原因。

## 本轮处理

新增 `tools/extract_south_sea_official.py`，从不可变的
`assets/map/svg/official-audit.svg` 按已核验的附图范围提取所有相交路径：

- 原始 `path d` 和 `transform` 原样复制；
- 保持官方 SVG 的完整 V viewBox，不进行 GIS 配准或比例变换；
- 只改变表现样式为深蓝/金色网页风格；
- 增加的深蓝矩形只是遮挡清洗层残缺内容的 presentation backdrop，不是地理几何；
- 短段对象仍记录为 `UNKNOWN`，没有命名为“九段线”，没有新增或重绘任何线段。

## 规范性边界

本地 EPS/SVG 能证明这些内容来自同一份官方图面，但不能单独证明短段对象的
正式符号语义，也不能替代自然资源主管部门的图例、产品说明和公开使用许可。
因此本派生层是“官方源保真恢复”，不是对九段线法律/制图语义的重新认定。

## 验收要求

1. 南海附图外框、岛屿群、标题/比例尺信息块仍可见；
2. 不出现空的嵌套框误导；
3. 主图国界、省界、海南、台湾不改变；
4. 官方 EPS、Audit SVG、Clean SVG 的 SHA-256 不变；
5. 派生元数据记录源 hash、范围、路径数和 UNKNOWN 对象。

正式公开或参赛提交前，仍需补充官方产品记录、图例/说明和审图/使用条款核验。
