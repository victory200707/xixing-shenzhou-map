# 视觉与交互规格

## 参考图的构图拆解

参考图为约 3:2 的桌面画布（1536×1024）。比例为设计目标的近似值，实际实现使用响应式约束而非固定像素。

| 区域 | 近似占比与位置 | 作用 |
| --- | --- | --- |
| 地图主舞台 | 左侧约 77% 宽、上部约 83% 高；从左边缘铺到右侧信息轨道前 | 第一视觉主体，承载中国几何、地形、晨光和动态分界 |
| 右侧信息轨道 | 约 23% 宽、从上部中段开始 | 地点对比、城市快捷选择、天文阶段和南海插图 |
| 顶部品牌/状态 | 左上约 24% 宽；经纬刻度横跨地图上沿 | 产品名称、中文副标题、当前节气/日期/时间 |
| 地图辅助元素 | 地图内部全幅 | 经/纬网、城市点和标签、活动地点光环、晨昏弧线 |
| 底部时间控制 | 全宽约 16–18% 高 | 播放、03:00–10:00 时间轴、摘要指标、四季卡片 |

地图必须在任何桌面首屏成为主角；右轨不能通过过度装饰抢占地图视觉权重。移动端将右轨折叠到地图下方，时间轴变为纵向或两行布局。

## 视觉层级

1. **背景层**：深海军蓝到近黑的底色，轻微径向暗角和低密度星点；不使用大面积渐变球或装饰性气泡。
2. **地理底层**：官方中国主体、国界、省界、海岸线、岛屿/南海插图；颜色保持低饱和深蓝灰，以便光照成为主叙事。
3. **地形层**：DEM 派生 hillshade/坡度纹理，裁切到官方主体 mask；只改变明暗与纹理，不改变边界。
4. **科学动态层**：按太阳高度角或晨光阶段着色的连续光场、晨昏分界线、太阳方位/轨迹辅助线。
5. **语义标记层**：城市点、名称、选中环、对比色、经纬刻度和必要注记。
6. **UI 层**：玻璃质感的半透明面板、时间轴、节气卡片和数据读数；使用 1px 低对比边框和局部发光。

## 色彩与质感方向

- 背景：`#031326`、`#071C32` 一类深蓝黑；海域比陆地更暗。
- 夜/曙光：深蓝 → 蓝灰 → 暖灰蓝 → 琥珀；连续插值优先，阶段色仅用于图例和读数。
- 日光焦点：金黄/橙黄，主要集中在太阳高度较高区域；避免全图统一橙色。
- 文字：主文字近白，次文字蓝灰，关键数值暖金；城市对比使用蓝/金两种稳定语义色。
- 发光：只用于太阳入射带、活动城市环和分界线；阴影应服务层级，不制造厚重卡片。

## 字体与图标

- 标题：需要确认是否有可用的品牌字稿；若无，使用已获许可的中文宋体/明朝体（如思源宋体或 Noto Serif CJK SC）并通过字距、描边和金色处理接近参考图。
- 正文/数据：系统无衬线中文字体，保证小字号可读。
- 图标：优先使用项目依赖的 Lucide 或同类开源图标；图标按钮需有可访问名称。
- 不下载未确认授权的商业字体，不把参考图中的标题直接裁成不可维护的图片作为唯一文本。

## 关键动效

- 时间轴拖动：光场、分界线、城市阶段和读数同步更新，过渡保持连续。
- 播放：默认 0.5–4× 可选，按动画帧或节流计算；播放范围可为 03:00–10:00，但科学引擎支持全天。
- 太阳光带：低频呼吸式亮度变化，不能影响数值读取。
- 面板：只做短距离淡入/位移，避免地图重排。
- 无障碍：`prefers-reduced-motion` 时停止呼吸和过渡，仍保持时间轴可用。

## 交互优先级

核心交互：时间轴拖动、播放/暂停、日期/节气切换、主/对比城市选择、地图城市点点击、信息面板联动。

辅助交互：播放速度、循环开关、图例展开、有限缩放/平移、显示层开关。辅助交互不能遮挡主地图，也不能让用户必须先配置复杂参数才能看到首屏叙事。

## 信息层级与响应式

- 顶部只展示品牌、节气、北京时间和当前日期；不堆叠科学参数。
- 右轨先给主/对比城市和日出差值，再提供完整参数抽屉。
- 底部先给播放与时间，再给摘要指标和四季预设。
- 所有面板有稳定的最小尺寸；文本溢出换行或截断，不得改变地图和时间轴布局。
