# 《曦行神州·万里晨光》设计说明

## 设计缘起与理念

每天清晨，太阳从东方升起，但中国各地并不会在同一时刻迎来光明。统一的北京时间方便了社会生活，却遮蔽了经度、纬度和季节造成的自然差异。当北京已经开始一天的工作时，西部高原可能仍处在黎明之前。作品由这一普通而真实的生活经验出发，试图回答：在同一个中国、同一个北京时间下，不同地方的人们如何迎接同一个太阳？

作品的核心理念是“让时间成为地图上的运动”。它不只报告某个城市的日出时间，而是把全国范围内晨光到达的先后关系转化为连续的空间叙事，使观众先感受地域差异，再理解其背后的天文原因。晨光边界既是视觉焦点，也是表现区域状态差异的动态地图符号。

## 设计方法

作品采用依法公开发布的标准中国地图资料作为地理事实底图，并依据其公开来源、版本和使用信息进行登记。国界、海岸线、省界、岛屿和南海附图保持源图结构，不以手绘、猜测或生成方式改变地图几何。地形采用项目高程数据派生的 hillshade、法线和多尺度纹理，只改变明暗与质感，不改变轮廓和城市位置。

太阳状态由真实计算产生。用户选择的北京时间先转换为 UTC 瞬时，系统依据 WGS84 经纬度计算太阳高度角和太阳方位角。底图坐标与计算坐标统一转换到同一 LCC 参考框架，再通过控制点建立地理坐标与 SVG 显示坐标的映射，对城市点、光场采样点和边界线进行一致性校正。作品采用太阳中心高度角约 −0.833° 的标准近似值定义日出，其中低于 −18°为天文夜，−18°至 −12°为天文曙光，−12°至 −6°为航海曙光，−6°至 −0.833°为民用曙光。当前结果表现理论太阳状态，不加入局地山脊遮挡和实时天气影响。

光影颜色由太阳高度角连续映射：深蓝代表夜面，蓝紫和灰蓝代表晨昏过渡，暗金至暖金代表日出后的陆地。暖光只作用于陆地视觉区域，海域和页面背景维持深蓝。这样，颜色变化既承担氛围塑造，也表达同一时刻不同区域的太阳阶段，避免成为覆盖整幅页面的装饰渐变。

## 版式与交互

页面采用“地图主舞台＋右侧信息区＋底部时间轴”的横向版式。地图位于左侧和中央，占据首屏最大面积，承载地形、晨光、动态分界、城市点和边界线，是第一视觉主体。右侧信息区展示北京、乌鲁木齐等城市的日出时刻、时间差、经度和太阳阶段，将空间现象转化为可比较的数据。底部时间轴显示北京时间、日期、城市日出节点和节气入口，默认提供 03:00 至 10:00 的观察范围，并支持连续播放和拖动。

交互按照“观察—比较—解释”展开。用户先观察全国晨光推进，再通过地点对比查看城市差异，随后进入天文阶段模式理解曙暮光定义，最后切换春分、夏至、秋分、冬至对应日期，比较太阳赤纬变化带来的空间差异。播放停止后，时间、阶段和城市读数仍保持可读，便于分析和截图。

## 作品价值与规范

图层严格分为背景、官方地理层、地形层、太阳动态层、语义标记层和界面层。官方地图几何始终位于动态光影之上，南海 inset 独立处理，避免地理事实被表现层遮挡。地图来源、数据日期、投影转换和派生资产均保留记录；视觉近似层只用于表达，不替代正式地理数据。

作品将天文计算转化为具有地图分析性的视觉体验：观众看到的不只是一条晨昏线，而是一个随北京时间变化的区域状态场；城市日出读数又为宏观画面提供量化参照。每一道晨光对应模型计算中的地理位置和时刻，反映理论太阳状态下中国各地的差异，也连接着人们开始一天生活的共同经验。
