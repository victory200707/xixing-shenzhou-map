# 《曦行神州·万里晨光》设计说明

《曦行神州·万里晨光》是一件以中国日出时空节律为主题的科学可视化地图作品。作品关注的不是某一个城市的日出时间，而是同一北京时间下，中国东、西、南、北不同地区如何处在不同的清晨阶段。通过地图、太阳计算、地形明暗和时间轴交互，作品把原本难以直观看见的时间差异转化为连续的空间叙事，让观众看到晨光如何在中国大地上展开。

作品的核心设计命题是“让时间成为地图上的运动”。中国地图作为第一视觉主体，占据首屏主要空间；右侧信息区和底部时间轴作为解释层，为地图上的现象提供数据依据。观众打开页面后，首先看到的是深蓝背景中的中国地图，以及由深蓝、蓝紫、暗金到暖金组成的昼夜过渡。随着时间轴推进，晨光边界连续移动，陆地颜色和城市数据同步变化，形成从夜晚到日出的完整过程。

视觉系统采用深海军蓝作为基础色，模拟日出前的低照度环境。海域和页面背景保持较深的蓝黑色，使中国陆地从背景中清晰分离。夜面使用冷蓝色，晨昏区域使用蓝紫、灰蓝和暗金的连续过渡，进入白昼后转为低饱和暖金色。暖色并非覆盖整幅地图，而是受太阳高度角控制，并限制在陆地视觉区域内，从而避免海域和界面被同强度染亮。金色只用于日出区域、关键数据和必要的分界强调，保证色彩具有明确的语义层级。

地形表现服务于晨光叙事，而不是单独展示地貌。作品使用高程派生的 hillshade、法线和多尺度纹理构成地形明暗层，通过降低整体对比度、保留山脉方向性和受光侧细节，使地形起伏成为光照变化的载体。地形层只改变明暗与质感，不改变中国轮廓、海岸线、省界和城市位置。这样既保留地图的识别性，也让西部高原、山地和东部平原在晨光推进中形成不同的视觉响应。

作品的科学逻辑建立在真实太阳位置计算之上。用户在界面中选择的北京时间会先转换为 UTC 瞬时，计算过程使用 WGS84 地理坐标、太阳高度角和太阳方位角，并通过项目登记的 LCC 投影与 SpatialBridge 坐标链映射到官方地图的 SVG V 坐标。每个光场采样点依据其经纬度计算太阳状态，颜色和透明度由太阳高度角连续决定，而不是通过屏幕左右位置强行指定。因此，地图上的明暗变化同时反映经度、纬度和季节因素。

交互设计围绕“观察、比较、解释”展开。底部时间轴提供 03:00 至 10:00 的连续播放和拖动，用户可以观察晨光边界的推进。地点对比模式突出北京与乌鲁木齐等城市的日出时间差，将宏观空间现象落到具体城市。天文阶段模式进一步展示天文晨光、航海晨光、民用晨光和日出等节点。春分、夏至、秋分、冬至四个节气入口，则用于比较太阳赤纬变化对全国晨光分布的影响。

地图图层采用严格分层结构：深蓝背景位于底层，官方中国地图和独立南海 inset 位于地理层，DEM 地形和太阳光场属于动态表现层，国界、省界、城市文字和城市点位位于其上，右侧面板与时间轴处于最上层。官方地图几何保持不变，所有视觉派生资产均记录来源、尺寸、viewBox 和处理信息。南海 inset 与中国大陆主体分开处理，避免把附图误当作大陆陆地数据。

本作品的价值在于把科学计算转化为具有审美秩序的视觉体验。它不把地图仅仅作为信息底图，也不把艺术效果建立在虚构地理几何之上，而是让真实时间、真实坐标和真实太阳运动共同产生画面变化。观众可以先感受晨光推进，再通过城市读数和天文阶段理解其原因，最终建立对中国地域尺度、统一时区和季节节律的直观认识。

《曦行神州·万里晨光》希望呈现的不是一张静态的中国地图，而是一块正在迎接太阳的土地：同一时刻，不同地方拥有不同的清晨；每一次颜色变化，都是时间、空间与太阳共同作用的结果。
