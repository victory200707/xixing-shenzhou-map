# 《曦行神州·万里晨光》设计说明

## 设计缘起与理念

每天清晨，太阳从东方升起，但中国各地并不会在同一时刻迎来光明。统一的北京时间方便了社会生活，却遮蔽了经度、纬度和季节造成的自然差异。当北京已经开始一天的工作时，西部高原可能仍处于黎明之前。作品由这一普通而真实的生活经验出发，试图回答：在同一个中国、同一个北京时间下，不同地方的人们如何迎接同一个太阳？

本作品的核心理念是“让时间成为地图上的运动”。它不只报告某个城市的日出时间，而是把全国范围内晨光到达的先后关系转化为连续的空间叙事，使观众先感受地域差异，再理解其背后的天文原因。

## 设计方法

作品以经过登记的官方中国地图资料作为地理事实底图，保持国界、海岸线、省界、岛屿和南海附图的原有结构，不以手绘、猜测或生成方式改变地图几何。地形采用项目高程数据派生的 hillshade、法线和多尺度纹理，只改变明暗与质感，不改变地图轮廓和城市位置。

太阳状态由真实计算产生。用户选择的北京时间先转换为 UTC 瞬时，系统依据 WGS84 经纬度计算太阳高度角和太阳方位角，再通过 LCC 投影及 SpatialBridge 坐标链映射到官方地图的 SVG V 坐标。日出采用太阳中心高度角约 −0.833° 的通行定义；太阳高度角低于 −18°、−12°、−6°时，分别表示天文夜、航海晨光和民用晨光阶段。作品当前表现的是理论太阳状态，未加入局地山脊遮挡和实时天气影响，避免把视觉近似误称为观测结果。

光影颜色由太阳高度角连续映射：深蓝代表夜面，蓝紫和灰蓝代表晨昏过渡，暗金至暖金代表日出后的陆地。暖光只作用于陆地视觉区域，海域和页面背景维持深蓝，从而让晨光边界成为可识别的地图信息，而不是覆盖整幅页面的装饰渐变。

## 版式与交互

页面采用“地图主舞台＋右侧信息区＋底部时间轴”的横向版式。地图位于左侧和中央，占据首屏最大面积，承载地形、晨光、昼夜分界、城市点和边界线，是第一视觉主体。右侧信息区展示北京、乌鲁木齐等城市的日出时刻、时间差、经度和太阳阶段，用于解释地图现象。底部时间轴连接播放、拖动、城市日出节点和节气入口，使时间变化成为可操作的地图组件。

交互按照“观察—比较—解释”展开。默认画面展示一个统一北京时间；用户拖动或播放 03:00 至 10:00 的时间轴，观察晨光推进；地点对比模式将全国现象落实到具体城市；天文阶段模式解释不同曙暮光节点；春分、夏至、秋分和冬至切换则用于比较季节变化。播放停止后，画面仍保留明确的时间、阶段和城市数据，便于阅读和截图。

## 作品价值与规范

图层严格分为背景、官方地理层、地形层、太阳动态层、语义标记层和界面层。官方地图几何始终位于动态光影之上，南海 inset 独立处理，避免地理事实被表现层遮挡。地图来源、高程数据、坐标转换和派生资产均保留记录，视觉层不替代正式地理数据。

作品将天文计算转化为具有审美秩序的地图体验：观众看到的不只是一条晨昏线，而是时间经过土地的过程。每一道晨光都对应真实的地点和时刻，也连接着人们开始一天生活的共同经验。作品希望让中国并不同步的清晨变得可见、可读、可比较，在科学规范与人文感受之间建立联系。
