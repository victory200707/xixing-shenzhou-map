## 1. 参考图地图结构

参考图尺寸为 1536×1024。地图不是印刷地图整页，而是一个固定全国视图：

- **主体显示范围**：约 70°E–140°E、18°N–55°N 的中国及近海视图；主体地图从左上向中下展开，西部和东北部保留完整轮廓，东南沿海、海南、台湾清晰可见。
- **主体构图位置**：地图约占首屏左侧 76% 宽度和 80% 高度；右侧约 24% 是信息面板，底部时间轴覆盖地图下缘。地图主体视觉中心在约 `(580, 440)`，不是页面几何中心。
- **南海框式插图**：主体地图右下、控制栏左侧有独立的深色圆角矩形插图，约 110×165 px；内部是南海诸岛点群、岛屿轮廓和环绕式短线标记，底部有“南海诸岛”标题。它是构图必需的独立组件，不是把主体地图无限向南缩小。
- **国界/海岸线**：细金色高亮线，夜侧偏蓝金，晨光侧转为暖金；外轮廓比省界更亮。
- **省界**：低对比度细线，叠加在地形纹理上；不能喧宾夺主。
- **海南/台湾**：按主体视图自然放置，并有独立城市点和标签；不是后期手绘图标。
- **经纬网**：顶部经度刻度、左侧纬度刻度和低透明度网格线，属于视觉辅助层，不是官方 EPS 的地理事实替代。
- **地形**：DEM/hillshade 与纹理叠加在官方陆地 Mask 内，西部深蓝、东部晨光金色，地形细节连续而非行政区填色。
- **晨光/昼夜分界**：一条弧形太阳分界线穿过中国主体，随时间轴移动；颜色场由太阳高度角连续计算。
- **背景/云层**：深蓝宇宙背景、低对比度云雾/星点和局部金色光晕，均为视觉生成层，不承担地理事实。

## 3. 三份 EPS 的实际南海检查

检查方式包括 Ghostscript 原始 EPS 渲染、南海区域放大预览、Corel `%Note: Object` 对象边界统计和对象流结构检索。EPS 内没有可直接检索的中文语义图层名；因此“对象存在”与“对象语义已证明”必须分开记录。

结构层面的可复核证据：

- 1:740 万 Corel 页面在右下南海区域出现约 `2480–2806 × 440–934` 的大范围对象边界，和渲染预览中的独立矩形 inset 对应；其内部还有大量较小岛屿、文字和短段对象。
- 1:1000 万 Corel 页面可见的主要大范围对象约止于 `x=1885`，对应主体地图；在页面右下空白区没有与 1:740 万同类的独立 inset 外框对象。其海域短段对象是主体页面内的分散对象。
- 1:2200 万正文使用 Illustrator 私有数据流，未出现可复用的命名图层或标准对象注释；南海框的存在由原 EPS 的 Ghostscript 渲染预览确认，但不能从普通文本扫描安全提取其语义层。

### 对“九段线”的严格结论

三份 EPS 都未提供可检索的“九段线”命名对象或语义图层。三份渲染预览均出现成组、重复、具有相近方向和样式的海上短段对象；1:2200 万和 1:740 万还把这些对象放入独立南海框中。它们**视觉上与九段线符号一致**，但仅凭 EPS 对象流不能证明其法律/制图语义。下一阶段必须取得官方图例、图层说明或出版元数据，逐对象确认后才能把该层命名为 `nine-dash-line`。

## 5. 是否继续使用 1:1000 万

**不应继续把 1:1000 万作为唯一 Master。** 可以保留它作为“主体线划候选”，用于独立 DEM/晨光视觉测试；但在用户确认前不能把它标记为最终 Master，也不能从其他 EPS 直接复制几何拼接。

## 6. 暂定官方资产组合（待确认，不是冻结）

建议进入下一轮核验的组合是：

1. **主体候选**：1:1000 万 Corel X8 的中国主体、国界、省界、海岸线、海南、台湾和可证明的岛屿路径。
2. **南海框候选**：1:2200 万 Illustrator 的官方南海框、南海诸岛和相关短段对象；1:740 万作为更高细节的交叉核对来源。
3. **视觉线划候选**：各候选的原始线型只作参考；最终边界颜色、阴影和发光由程序重建。
4. **禁止混合项**：在投影、版本、审图号、对象语义和许可未确认前，不把三个 EPS 的边界路径无标记地合并成一份几何。

该组合的关键是把“主体地图”和“南海独立 inset”作为两个官方资产域，再由网页容器组合；不是把南海 inset 拉伸回主体地图坐标，也不是重绘九段线。

## 7. 最终网页地图组合方式

```text
官方主体候选（1:1000 万） ──> 主体 SVG / land mask / boundary layers
官方南海框候选（1:2200 万，1:740 万核对） ──> 独立 inset SVG / island layers
官方投影与控制点确认 ──> 同一 manifest 的坐标与版本登记
DEM ──> 只裁切主体 land mask 的 hillshade
太阳计算 ──> 晨光、昼夜分界、光照色场
网页布局 ──> 主体地图 + 右下南海 inset + 右侧信息栏 + 时间轴
```

在执行派生前必须完成：正式来源/审图号/许可确认；三个文件的比例尺、投影或控制点核验；南海框与短段对象的官方语义核验；主体与 inset 的版本登记。完成这些核验后，才决定是保留 1:1000 主体候选，还是改用含完整 inset 的 1:2200 万作为统一来源。

## 8. 本阶段结论

- 用户提供的附件就是本项目逻辑资源 `assets/reference/xixing-reference.png`；仓库中目前尚无同名实体文件。
- 1:1000 万不能单独复刻参考图的地图构图，之前的唯一 Master 推荐撤回。
- 1:2200 万和 1:740 万实际包含独立南海框；1:1000 万没有同等框式 inset。
- 三份 EPS 都没有可验证的语义图层名称来直接证明“九段线”；只能记录为待官方元数据确认的短段对象。
- 当前不冻结 `MASTER_MAP`，不生成最终地图资产，不进入网站 UI 开发。

下一步（需用户确认后）：只做三份 EPS 的南海对象逐对象分类、官方图例/审图元数据核验和比例尺/控制点登记。
