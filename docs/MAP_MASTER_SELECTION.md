## 历史技术评估（未冻结）

本文件记录三份 EPS 的首次技术评估。其“1:1000 万作为唯一 MASTER_MAP”的结论已被 Phase 1A.5 撤回；当前有效结论以 `docs/PHASE1A5_REFERENCE_FIT.md` 为准。

当时的选择依据不是原文件的颜色，而是：版本较新、地理要素完整、线划底图给视觉系统最大改造空间、Corel EPS 的对象序列可被程序化检查，且比 Illustrator 私有编码更适合后续网页派生。该判断未充分纳入参考图的南海框式构图，因此不再作为最终推荐。

这是已被 Phase 1A.5 撤回的历史技术推荐，不等同于发布许可确认。用户仍需确认正式来源、审图号、派生发布许可，以及预览中蓝色水系/水域标记的确切语义。

## 实际检查方法

1. 对三个压缩包逐一解包到 `analysis/phase1a/`，原 EPS 不回写。
2. 读取 EPS 头部：Creator、CreationDate、BoundingBox、LanguageLevel、文件编码和资源标记。
3. 使用 Ghostscript 10.07.1 的 `bbox` 设备核对有效图面范围，并用 `-dEPSCrop` 生成 PNG 预览。
4. 对 Corel EPS 的页面段统计 `%Note: Object`、对象边界框、路径命令和填充/轮廓操作；这些是词法统计，不是未经验证的 GIS 要素数量。
5. 对 Illustrator EPS 检查 Adobe 私有资源、`%%BeginData`、XMP 和图层标记；该文件没有可识别的 `BeginLayer/EndLayer` 标记。

分析预览和中间文件仅用于审查，不是最终网站资产。

## 地理内容比较

### 1:2200 万

- 预览显示中国主体外轮廓、一级行政区界线、海岸线、海南、台湾及其他岛屿标记。
- 右下有南海诸岛插图；图例、比例尺、城市点/名称和部分水系标注也在同一画面内。
- 图面经过概览级简化，城市与省界密度较低，适合全国叙事但不适合继续放大查询。
- 文件名为“无邻国、线划版”，没有把邻国几何作为产品必须依赖。

### 1:740 万

- 预览显示中国主体、分省行政区填色、较密集省界和市县级城市标记。
- 可见较多蓝色水系、海域文字、海岸与岛屿；右下有南海插图和独立比例尺。
- 内容最丰富，适合人工核对地理要素，但城市、文字、河流和省色会给网页拆层带来大量清理工作。
- 原始颜色不应直接进入产品；它们仅说明对象之间存在可利用的填色边界。

### 1:1000 万

- 预览显示中国主体、全国外轮廓、一级行政区界线、海岸线、海南、台湾及岛屿标记，右下保留南海相关插图。
- 是线划版，省色和大面积印刷底色较少，适合作为自建夜色、DEM 和晨光系统的几何底座。
- 标题包含“无河流”，但裁切预览仍能看到蓝色水域/线状标记；这可能是海岸、水域名称或隐藏水系对象，必须在下一步图层审查中确认，不能只按文件名推断。
- 城市和说明文字仍混在图面中，不能直接把整页作为网页 SVG；需要隔离地理路径和注记。

## 几何与对象实测

### Corel EPS 的可比统计

| 指标 | 1:740 万 | 1:1000 万 | 解释 |
| --- | ---: | ---: | --- |
| `%Note: Object` | 4,640 | 3,962 | Corel 导出的对象记录数量，包含重复/印刷对象 |
| 唯一对象边界框 | 3,298 | 2,618 | 相同 bbox 的对象仍可能是不同描边/填充 |
| 重复 bbox 数 | 1,342 | 1,344 | 约三成对象存在重复范围，不能直接当成几何错误；常见于填充+描边或文字叠印 |
| `moveto` 词法计数 | 11,460 | 9,267 | 路径复杂度参考，不是 feature 数量 |
| 曲线命令计数 | 169,667 | 173,385 | 1:1000 万边线曲线更密 |
| 直线命令计数 | 62,866 | 43,367 | 1:740 万含更多直线/标记对象 |
| `closepath`/等价闭合计数 | 10,767 | 7,691 | 对 mask 闭合性有帮助，但仍需路径级验证 |

两个 Corel 文件都能被 Ghostscript 无错误渲染，说明 PostScript 级语法和页面绘制是完整的；但对象序列没有语义图层，重复 bbox 也不能未经验证地删除。

### 1:2200 万的结构特征

- EPS 头部标记为 Illustrator 13.0，包含 Adobe AGM/CoolType 私有 procset 和一个 `%%BeginData: 11871 Hex Bytes` 数据块。
- 文件包含 XMP 和嵌入式 256×196 JPEG 缩略图；正文没有可检索的 `AI*_BeginLayer/EndLayer` 图层标记。
- 页面能被 Ghostscript 正确渲染，但普通正则只能看到少量标准路径命令，说明主要绘制数据使用 Illustrator 私有压缩/宏，不适合直接按标准 PostScript 文本拆分。
- 它不是“坏文件”，而是网页转换时需要 Illustrator/兼容解析器或先转为可验证中间格式的文件。

## 图层结构与拆分难度

三个 EPS 都没有提供可直接复用的、语义清晰的网页图层树：

- 1:2200 万：Adobe XMP 只见到色板组，未见可用的命名图层标记；私有宏使路径定位困难。
- 1:740 万：Corel 页面是平铺的 `@rax %Note: Object` 序列，填充/轮廓颜色写在对象前；没有行政区、河流、城市等命名层。
- 1:1000 万：同样是平铺对象序列，但线划与无省色特征减少了要剥离的视觉样式。

因此，后续“拆层”不能理解为读取现成图层，而是建立一套保守的对象分类与人工核验流程：按源颜色/描边/对象范围/闭合关系分组，生成候选层，再与原始渲染预览叠加比对。任何不能证明语义的对象都保留为待审核状态。

## 网页派生可行性

### SVG

- **1:1000 万：可行性最高**。Corel PostScript 明文对象较多，线划底图可转成 SVG path；需要处理大尺寸、文字轮廓、重复对象和页面裁切。
- **1:740 万：可行**。填充省界可帮助形成候选面，但对象数量、颜色、河流、城市标注密集，拆层和文件体积控制更难。
- **1:2200 万：可行但风险最高**。可先通过支持 Illustrator EPS 的工具转 SVG/PDF，再逐层核验；不建议用普通文本替换或自行重建路径。

### GeoJSON

EPS 没有在头部提供可直接使用的 CRS。不得从图片边缘猜经纬度，也不得用第三方中国轮廓替代。只有在确认原图投影或取得足够经纬控制点、并通过边界叠加误差测试后，才生成 GeoJSON。若本项目保持固定全国视图，SVG + `map-manifest.json` 的地图坐标也可以先满足动态渲染，GeoJSON 不应为了“标准格式”强行生成。

### Mask

- 1:740 万的省级填充面最容易生成候选 land mask，但不得把省色本身当最终视觉层。
- 1:1000 万需要从闭合外轮廓/面对象构建 mask；若对象无法可靠闭合，使用原始矢量渲染得到的二值 mask，再用边界叠加和像素回归验证。
- 1:2200 万可由外轮廓生成，但 Illustrator 私有路径拆分成本最高。

### DEM 与动态光照

三份候选都可以在不改变地理几何的前提下叠加 DEM：先生成独立 hillshade/高程纹理，再用 Master 的 land mask 裁切；动态晨光只修改颜色、亮度和光晕。Master 中的城市、河流、印刷色和图例不应被当作地形数据。

## Master 必须原样保留的内容

从 1:1000 万 Master 派生时，以下地理事实必须与源文件保持一致：

- 中国主体外轮廓和国界几何。
- 一级行政区边界的拓扑关系与位置。
- 海岸线、海南、台湾和其他应展示岛屿的几何。
- 南海相关插图、岛屿位置关系和必要的官方标注。
- 如果下一步确认蓝色线状对象属于官方水系/海岸要素，则其几何也必须原样保留；如果只是印刷辅助线，必须有证据后才可不进入动态层。

## 可以重新表现的内容

- 陆地和海域颜色、透明度、夜色/晨光色带。
- DEM hillshade、高程纹理、阴影和宏观地形质感。
- 晨昏分界线、太阳光带、光晕和星点。
- 经纬网线型、城市标记样式、标签字体和信息面板。
- 参考图中的标题、UI、时间轴、节气卡片和动效。
- 原始图例、印刷色、比例尺和非必要说明文字（但是否隐藏要在最终地图使用规范下确认；隐藏不等于删除源资产）。

## Master 派生计划（历史草案，当前暂停）

1. 冻结 `MASTER_MAP` 源压缩包和 EPS 哈希，登记审图号、来源、许可和用户确认状态。
2. 在兼容 Corel EPS 的矢量工具中建立只读副本，按对象样式和闭合关系标记候选 `land`, `national-boundary`, `province-boundary`, `coastline`, `islands`, `south-sea-inset`, `hydrography`, `labels`, `legend`。
3. 先导出保留几何的 SVG，禁止路径平滑、简化或自由重绘；输出 `viewBox`、转换器版本和对象分类报告。
4. 只有确认投影/控制点后才输出 GeoJSON；若没有可靠 CRS，先保留 SVG 坐标和 `projectLonLat()` 控制点配置，不生成伪 GeoJSON。
5. 从确认后的 land/coast/islands 生成独立 mask；mask 版本必须与 SVG 的源 hash 和几何校验绑定。
6. 单独导出边界、海岸线、岛屿、南海插图和可选水系层，使用同一地图坐标系；每层保留原始路径引用。
7. 用 1:1000 万源图裁切预览、派生 SVG、mask 和合成图做像素/边界回归，确认没有缺省、漂移、闭合错误或岛屿丢失。

## Phase 1A 历史结论与当前门槛

技术评估曾推荐 `1:1000 万 Corel 线划 EPS`，但该推荐已由 Phase 1A.5 撤回。当前不冻结 `MASTER_MAP`；请先阅读 `docs/PHASE1A5_REFERENCE_FIT.md`，完成参考图适配、南海对象语义和官方元数据核验后再重新决策。
