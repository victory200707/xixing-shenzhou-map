# 项目定义

## 一句话定义

以官方中国地图为地理事实底图，实时计算太阳状态，把晨昏、日出时间差与节气变化投影成可播放的中国晨光时空叙事。

## 产品理解

这不是“显示某个城市日出时间”的工具，而是一个以中国为整体观察对象的科学可视化作品。用户在统一的北京时间下看到晨光从西向东推进、不同纬度在季节中的变化，以及城市之间日出节律的差异。地图是第一主角，数据面板用于解释当前画面，时间轴用于让节律成为可感知的运动。

## 首屏叙事

1. **第一眼**：看到一张占据大部分视口的中国晨光地图，西部处于深蓝/曙光，东部被金色日光覆盖，明确感受到“同一北京时间、不同晨光阶段”。
2. **第二步**：理解顶部日期和北京时间、地图上的晨昏分界、城市标记及右侧对比读数分别在回答什么问题。
3. **操作时间轴后**：看到晨光边界连续移动，颜色和城市读数同步变化，感受到经度、纬度和季节共同塑造的时间节律，而不是只看到数字跳动。
4. **城市对比的价值**：把宏观地图现象落到可解释的城市差异，帮助用户区分经度导致的时差、纬度导致的季节变化，以及北京时间统一带来的生活经验。
5. **节气的价值**：用春分、夏至、秋分、冬至四个稳定参照点展示太阳赤纬改变后昼夜分布和晨光推进方式的变化。

## 核心用户与场景

- 对公众：快速理解中国地域尺度上的日出节律。
- 对展览/竞赛评审：首屏即呈现完整视觉叙事，播放后能看出科学逻辑。
- 对教育/科普：通过城市对比和节气预设解释太阳高度角、日出和时区。

## MVP 范围

- 官方地图几何与南海插图的合规展示。
- 一个日期（默认参考图中的 2026-06-21）和北京时间时间轴。
- 太阳高度角驱动的晨光阶段和昼夜分界。
- 城市点、名称、主城市/对比城市读数。
- 春分、夏至、秋分、冬至切换。
- 播放/暂停、拖动、日期/节气切换、城市选择和信息面板联动。

## 明确不纳入首阶段

- 气象云量、实际观测天气和城市级空气质量。
- 精细局地山脊遮挡、建筑物遮挡和实时卫星云图。
- 任意缩放到省市级的完整 GIS 查询系统。
- AI 生成或手工重构任何中国地图几何。

## 成功标准

- 地图几何与用户确认的官方源逐点一致，派生文件可追溯。
- 时间轴连续播放时，太阳场、分界线、城市数据和面板无不同步现象。
- 关键太阳事件与独立算法交叉验证在约 1 分钟内；地图场高度角误差目标不超过 0.01°（沿用旧项目验证标准）。
- 在目标桌面视口首屏保持地图主导、信息层级清晰，并在窄屏有可用降级布局。

## 阶段状态

当前进入 Phase 1C-1（视觉重构与布局初始化）。Phase 1B-1、Phase 1B-2 和
Phase 1B-3 Mock 已完成：官方 EPS 已归档为不可变源，人工验收通过的
`assets/map/svg/official-audit.svg` 已冻结，G-P-V SpatialBridge 参数已登记，
DEM 模拟管线已输出固定尺寸测试纹理。真实 DEM、天文引擎和动态晨光仍未接入。

历史来源与许可核验记录继续保留在 `docs/MAP_SOURCE_VERIFICATION.md`；它不再
阻塞当前静态视觉骨架，但在公开发布前仍须完成法律与来源复核。

## 当前缺失项与责任边界

### 必须提供或确认

- 最终采用的官方 EPS 版本、来源机构、审图号、公开发布许可和署名方式。
- 是否允许将 EPS 派生为网页 SVG/GeoJSON/mask，以及派生文件是否可以随站点发布。
- 旧项目快照是否是允许迁移的最新版本；若不是，请提供正式仓库或指定 commit。
- 是否要求标题字形与参考图一致；如要求，请提供已获许可的字体或品牌字稿。

### 建议提供

- 首批城市名单、城市标签优先级和默认主/对比城市。
- 目标首屏设备/分辨率、是否需要移动端完整体验、目标帧率。
- 是否要把理论日出升级为考虑地形遮挡的模型。

### 可以由项目自行获取

- 经许可的 30–90 m DEM 及其派生 hillshade。
- 权威城市坐标/名称交叉核验资料。
- 开源图标库和系统/开源中文字体。

### 可以由程序计算或生成

- 太阳位置、太阳高度角/方位角、日出/日落/曙光、节气和时间轴插值。
- 晨光/昼夜分界、DEM 光照叠加、星点、背景纹理、光晕和 UI 动效。

## 当前下一步

Phase 1C-1 只建立参考图首屏的静态 HTML/CSS/JS 容器：背景、官方 Audit SVG
主体、右侧玻璃面板和底部时间轴占位符。所有读数使用明确的占位值，完成后再
进入真实科学数据与动态渲染接入。
