# Phase 1C-45：自有风格视觉收敛

## 本轮目标

依据专业视觉评审，减少地图内部的噪点和发光边缘，让晨光成为第一视觉主体；地图比例、官方 SVG 几何、天文计算和交互保持不变。

## 调整内容

- 地形层整体透明度由强展示调整为克制浮雕，降低高频锐化和 multiply 强度。
- 夜面进一步压低为深海军蓝，晨光过渡改为更平滑的冷蓝、蓝紫、暗金序列。
- 日出后的颜色改为更干净的低饱和琥珀暖金，减少灰棕滤镜感。
- 晨昏暖光 bloom 降低，保留宽过渡带和细核心线。
- 官方线划、外轮廓和南海 inset 的亮度及光晕降低，避免“发光贴纸感”。
- 城市名称略微弱化，城市点位和交互状态保持可识别。

## 未改变内容

- 官方 `presentation-coastline.svg` 几何未修改。
- UTC、WGS84、太阳高度角、太阳方位角、LCC、SpatialBridge 和 SVG V 坐标链未修改。
- 地图主体比例未缩小。
- 南海 inset 继续独立于大陆太阳场。
