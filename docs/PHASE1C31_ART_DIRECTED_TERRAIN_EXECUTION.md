# Phase 1C-31: 参考图式地形光影执行报告

## 1. 执行目标

在不改变官方地图几何、城市坐标、南海附图和太阳计算链的前提下，
将当前“陆地颜色随太阳高度角变化”的原型推进为参考图式的地形光影：

- 西部未日出陆地保持深蓝，同时保留可读的山脊与谷地；
- 晨昏区域形成宽而柔和的蓝紫、灰紫、暗金过渡；
- 已日出区域不是整块平涂，而是暖金色与受光山脊共同变化；
- 受光侧有克制的暖雾和边缘辉光，但不覆盖官方线划；
- 海域和页面背景维持深蓝，不被大面积暖色染亮。

参考图是视觉目标，不是地理数据来源。最终效果允许艺术化增强，但不得伪造
国界、海岸线、省界、城市和山脉几何。

## 2. 当前版本的限制

Phase 1C-30 已解决太阳 Canvas 被官方陆地填充遮挡的问题，晨昏推进能够显现。
但现有地形仍主要来自已烘焙的视觉 hillshade，当前方向性受光是从灰度纹理梯度
估算出来的，不是从原始高程计算出的真实坡向。因此：

- 山脊高光方向不够稳定；
- 地形纹理容易整体同亮或同暗；
- 西藏和西部高原难以形成参考图中的立体层次；
- 继续只调颜色和光晕，无法解决根本问题。

## 3. 执行路线

### 阶段 A：建立 DEM 地形基础

优先使用 Copernicus DEM GLO-30，无法取得时使用 SRTM 30m。数据覆盖中国大陆、
海南和台湾，并记录来源、版本、许可证、下载日期和 SHA-256。

处理链：

```text
原始 DEM(WGS84) → 拼接与 NoData 处理 → LCC 投影
→ SpatialBridge → SVG V 坐标 → 与地图显示矩形一致的栅格
```

DEM 仅用于地形起伏和光照，不参与国界、海岸线、城市定位或南海内容。

### 阶段 B：生成多尺度地形光照资产

由原始高程计算：

1. 低频地形：表现高原、盆地和山系的整体起伏；
2. 高频地形：表现山脊、沟谷和局部纹理；
3. 坡度与坡向：生成每个像素的地形法向量；
4. 环境遮蔽：压低深谷和背光地形，避免全图平亮；
5. 基础 hillshade：作为低强度静态地形底。

最终输出只改变明暗和材质，不改变任何地图轮廓。

### 阶段 C：太阳方向光照

保留现有 UTC、WGS84、太阳高度角、太阳方位角、LCC 和 SpatialBridge 链路。
每个地形像素使用：

```text
directLight = max(0, terrainNormal · sunDirection)
terrainLight = ambientLight + directLight × solarAltitudeWeight
```

太阳高度角负责“昼夜和晨昏阶段”，太阳方位角负责“哪一侧山坡变亮”。
不使用屏幕左右位置直接指定昼夜颜色。

### 阶段 D：艺术化颜色与大气层

将科学结果映射到参考图式色阶：

```text
深夜蓝 → 蓝灰 → 蓝紫 → 暖灰 → 暗金 → 低饱和暖金 → 局部橙白高光
```

艺术化增强分为独立层：

- 地形颜色层：只在陆地 Mask 内改变地表颜色；
- 受光山脊层：由坡面受光强度驱动；
- 晨昏柔光层：围绕真实太阳高度角边界扩散；
- 海岸边缘辉光：低强度、仅作视觉提示；
- 官方线划层：始终位于所有光影之上。

辉光不得替代地形光照，不得形成固定斜线、矩形或梯形色块。

## 4. 图层顺序

```text
深蓝背景
→ 低频/高频 DEM 地形层
→ 陆地太阳方向光照层
→ 晨昏柔光与受光侧雾化层
→ 官方主图线划与边界
→ 南海独立附图
→ 城市标记
→ 右侧面板与时间轴
```

主图 Mask 与南海 inset 必须分开。南海 inset 不参与大陆 DEM Mask，也不接受主图
太阳场的裁切。

## 5. 验收标准

使用夏至 `2026-06-21` 的 `05:00`、`06:00`、`08:00` BJT 验收：

- 太阳推进方向和城市日出数据一致；
- 西部夜面深蓝但仍能看见地形结构；
- 东部受光区域连续暖金，山脊和谷地有方向性差异；
- 晨昏带有宽度，不是一条孤立亮线；
- 西藏南部、台湾、海南无缺口或漂移；
- 光影边缘与当前官方地图完全重合；
- 海域和页面背景不出现同强度的大面积暖色；
- 官方国界、省界、城市名称和城市点位清晰；
- 南海附图保持独立、稳定；
- 时间轴连续播放不出现明显卡顿；
- 控制台 error/warn 为 0。

## 6. 约束与风险

- 参考图包含电影化的高光、雾化和色彩分级，不能作为正式地理精度标准；
- 若继续使用现有低分辨率 hillshade，只能得到近似视觉效果，不能宣称真实 DEM 光照；
- DEM 和官方地图投影或显示矩形若有偏差，会再次造成西藏等区域错位；
- 所有派生资产必须保留源文件、处理脚本、参数和校验记录；
- 不修改官方 EPS/SVG，不手绘或 AI 补全地理轮廓。

## 7. 交付物

- DEM 源数据及来源记录；
- 与 SVG V 坐标对齐的高程/法线/多尺度 hillshade 资产；
- 更新后的太阳方向地形合成模块；
- 艺术化晨昏柔光参数记录；
- 05:00、06:00、08:00 宽屏验收截图；
- 阶段报告与控制台、性能和对齐验证记录。

本轮已落地的第一项交付：`assets/map/raster/dem-elevation-v.png`。它由项目现有
35 张 Terrarium 高程瓦片按同一 LCC/SpatialBridge 链路重采样到 SVG V 坐标，作为
浏览器坡度/坡向分析输入；它是视觉分析资产，不是地理边界数据。

## 结论

参考图式效果可以实现到接近其核心观感，但关键升级是“从原始 DEM 计算地形法线，
再让太阳方向光照改变地形明暗”。颜色、光晕和雾化只作为最后的艺术化增强，不能继续
作为地形起伏的替代方案。
