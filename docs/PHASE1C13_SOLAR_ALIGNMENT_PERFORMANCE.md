# Phase 1C-13：光场贴合、晨昏线与播放优化

## 问题与修正

上一版为了隐藏西藏南部的边缘差异，对近似视觉 Mask 进行了 4 CSS px 扩张。这会让暖金昼面溢出官方海岸/国界线，不能保留。

本轮已改为：

- 取消 Mask 几何扩张，直接按大陆与台湾的原始近似 Mask 进行裁切；
- 保留 Mask 本身已有的轻微 alpha 羽化，降低近似边缘与官方线划之间的可见差异；
- 官方 SVG 继续在光场上方，承担唯一的国界、省界、海岸线和岛屿表示；
- 晨昏线采用真实太阳高度角 `-0.833°` 的连续暖金细线，宽度 1.35px、低强度光晕；
- 将光场采样比例由 0.75 调整到 0.38，并缓存不随时间改变的低频地势材质；
- 时间轴拖动与播放改为 `requestAnimationFrame` 合并渲染，避免输入事件堆积。

## 限制

大陆和台湾 Mask 均为 Natural Earth 近似视觉裁切层。它们不能替代官方地图几何，也不能用于正式边界审查或地图发布。
