# Phase 1C-19：同源线划视觉陆地色层

## 结论

太阳光场现在使用当前页面实际显示的 `presentation-coastline.svg` 作为输入，在同一 SVG V 坐标和同一 `object-fit: contain` 显示矩形内生成扫描线视觉 Mask。它替换了 Natural Earth 的运行时 Mask，解决了两套地图边界不一致造成的光影漂移。

`APPROXIMATE_VISUAL_MASK — NOT A GEOGRAPHIC SOURCE`

该层仅用于陆地颜色裁切，不定义国界、省界、城市坐标、南海内容或任何地图事实。官方 SVG 仍位于光场之上，几何和文字未修改。

## 实现

- 保留 UTC、WGS84、太阳高度角、LCC、SpatialBridge 和 SVG V 坐标链。
- 从同源线划的 alpha 像素提取每行主体外包络，填充连续陆地区域。
- 叠加同 V 坐标的保守主体范围 guard，过滤省界横线、附图线和孤立标注，防止生成矩形伪影。
- 仅桥接短的抗锯齿断行，并使用小范围羽化，避免硬边。
- 台湾继续使用独立视觉 Mask；南海 inset 不参与大陆 Mask。
- 未使用固定屏幕渐变、矩形/梯形填充或手绘轮廓。
- `1123.svg` 的外轮廓候选保留在 `assets/map/svg/1123-land-mask-v.svg` 供审计；由于源路径开放，未直接作为生产填充面。
